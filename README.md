# ❌⭕ Jogo da Velha em Python

Um projeto simples e interativo do clássico **Jogo da Velha** (Tic-Tac-Toe), desenvolvido em Python para execução diretamente no terminal.

Este projeto foi construído para praticar conceitos fundamentais de programação, como **estruturas de repetição (`while`)**, **condicionais (`if/elif/else`)**, **listas** e **funções**.

---
## 🎮 Como Funciona

1. O tabuleiro é exibido com posições numeradas de **1 a 9**.
2. Os jogadores alternam entre **'X'** e **'O'**.
3. O jogador escolhe o número da casa onde deseja jogar.
4. O programa valida se a posição digitada está livre e dentro do intervalo.
5. O jogo encerra automaticamente quando um jogador vence ou quando ocorre um empate ("Deu Velha!").
